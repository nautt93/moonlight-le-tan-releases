# Moonlight Lễ tân

Ứng dụng lễ tân Moonlight Hotel dành cho Windows 64-bit, hỗ trợ máy đọc căn cước RAR-DTA.

1. Mở [bản phát hành mới nhất](https://github.com/nautt93/moonlight-le-tan-releases/releases/latest) và tải tệp `*-Windows-x64-Setup.exe`.
2. Chạy bộ cài rồi mở **Moonlight Lễ tân**.
3. Dùng menu **Cập nhật → Kiểm tra cập nhật** để xem phiên bản mới.

Các bản phát hành có bộ cài, tệp SHA-256 và tệp cập nhật có chữ ký để ứng dụng xác minh trước khi cài.
